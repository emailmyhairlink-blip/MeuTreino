# Meu Treino — aplicativo instalável

## Como testar
Dentro desta pasta, execute `python -m http.server 8080` e abra `http://localhost:8080`.

## Como publicar gratuitamente
Envie a pasta para Netlify, Vercel ou GitHub Pages.

## Como instalar no Android
Abra o link publicado no Chrome e toque em **Instalar** ou em **Adicionar à tela inicial**.

Os dados ficam no próprio aparelho. Use **Exportar dados** antes de limpar o navegador ou trocar de celular.
